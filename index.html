Camelot Web Tools (CWT)

A 100% client-side multi-tool suite offering 79 utilities for freelancers, contractors, and small businesses—including vector PDF form filling and Bates stamping, invoice generation, e-signatures, document conversion, and financial calculators. Runs entirely inside the browser and desktop runtimes with zero external server dependencies.

  • Integer-cent currency arithmetic eliminating IEEE-754 floating-point errors.
  • In-memory Bates stamping with sequential numbering across multi-page PDF bundles.
  • Client-side cryptographic hashing envelopes and PDF generation via pdf-lib.
  • MCP Server package (camelotwebtools-mcp) providing 79 tools directly to AI assistants.
React 18 TypeScript Vite Tailwind CSS Electron pdf-lib IndexedDB

Camelot Web Tools: Mobile App

The native Android edition of Camelot Web Tools, built with Kotlin and Jetpack Compose. Delivers the complete 75+ utility catalog offline on Android 15+ devices using AndroidX WebViewAssetLoader for local asset virtualization and MediaStore Scoped Storage for instantaneous PDF exports.

  • Offline execution: entire catalog runs on-device with zero server pings.
  • WebViewAssetLoader virtual domain bypassing CORS and file-scheme restrictions.
  • Android MediaStore Scoped Storage integration for instantaneous PDF exports.
  • Signed and compiled as an optimized release .AAB for Google Play.

Production Prototype Bioinformatics • 4D WebGL

ORIGO: Deep-Time Ancestral Atlas

An interactive bioinformatics platform that reconstructs 300,000 years of human migration. Users can upload raw DNA data (23andMe, AncestryDNA, or VCF files), which is decompressed and parsed entirely client-side to map Y-DNA and mtDNA lineages onto an interactive 4D Three.js WebGL globe with temporal scrubbing.

  • Universal client-side genomic parser decompressing .vcf.gz using in-memory pako.
  • Phylogenetic resolver mapping paternal Y-DNA and maternal mtDNA branches to archaeological cultures.
  • Interactive 4D Three.js WebGL globe with dynamic temporal scrubbing from 300,000 BCE to modern day.
  • Evidence Workbench correlating genetic claims with published DOI citations and radiocarbon-dated fossils.
React 19 Three.js React Three Fiber XState v5 Leaflet D3-Scale pako

About William

Developer & Business Owner

I was born in Oklahoma City and live and work here today. I am a full-stack web developer, native Android mobile developer, and independent tech founder.

My primary focus over the last several years has been building Camelot Web Tools from the ground up—writing the client-side calculation and document generation engines in TypeScript, designing the UI, packaging desktop builds with Electron, and porting the entire system to native Android with Kotlin and Jetpack Compose.

Outside of CWT, I build simulations and data tools, including an agricultural genetics game powered by Google Gemini and a 4D population genetics atlas that parses raw genome files in the browser.

If you want to talk about a project, collaborate, or hire me for web or mobile development, feel free to reach out directly.
