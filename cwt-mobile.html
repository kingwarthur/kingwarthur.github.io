Mobile Architecture: Zero-Cloud Native Hybrid

Rather than maintaining separate, diverging calculation codebases across Android and web, the CWT Mobile architecture employs AndroidX WebViewAssetLoader to serve pre-compiled, optimized web bundles from local APK/AAB assets.

By establishing a virtual secure origin at https://appassets.androidplatform.net/assets/, the application completely bypasses CORS restrictions, local file-scheme limitations (file:///), and modern Android security blocks. The app runs 100% offline, guaranteeing instant cold boot times without hitting remote servers.

Key Native Android Subsystems

1. Scoped Storage & MediaStore PDF Export

In compliance with modern Android 11+ (API 30+) and Android 15 (API 36) storage requirements, the app uses MediaStore.Downloads and content:// URIs. Invoices, Bates-stamped PDFs, and CSV exports are written directly to public downloads with zero legacy storage permissions (WRITE_EXTERNAL_STORAGE is completely avoided).

2. Native Print Manager Integration

A two-way JavaScript interface (@JavascriptInterface) exposes native printing services via android.print.PrintManager. When a user clicks "Print" on an invoice or balance sheet, base64-encoded PDF bytes are decoded into an isolated cache file and streamed into a native Android PrintDocumentAdapter.

3. Hardened WebSettings & Surface Security

Network access is strictly locked down: setAllowFileAccess(false) and setAllowContentAccess(false) prevent arbitrary filesystem traversal. The web view only communicates through the sandboxed virtual asset loader.
